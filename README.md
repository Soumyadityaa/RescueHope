# Animal Rescue & Shelter Initiative - Frontend Prototype

A modern, responsive, and professional web interface for an animal welfare non-profit organization. Built strictly with HTML5, CSS3, and Vanilla JavaScript.

## Features
- **Responsive Design:** Mobile-first architecture scaling perfectly to desktop.
- **Interactive UI:** Animated statistics, dynamic filtering for animal adoption, and smooth accordions.
- **Mock Authentication & Dashboards:** Uses `localStorage` to simulate user logins and track donation history.
- **Donation System:** Client-side validation and flow for capturing donation details.
- **Emergency Reporting:** Forms configured for urgent rescue reporting.
